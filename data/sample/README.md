# Illustrative sample

`malice_sample.csv` contains **30 rows** (15 code-mixed + 15 transliterated) drawn from the MALICE
corpus. It exists only to demonstrate the schema and let you try the tooling in
[`../../scripts/load_malice.py`](../../scripts/load_malice.py).

It is **not** a representative or complete sample — it is a tiny excerpt. The full ~250K-prompt
corpus is gated; see [`../../ACCESS.md`](../../ACCESS.md).

Columns: `seed_prompt`, `malice_prompt`, `type`, `languages`.
